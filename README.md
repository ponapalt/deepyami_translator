# DeepYami翻訳アプリ

LangChainと複数のLLMモデルを使用した、DeepL風の翻訳アプリケーション

## 機能

- 🌐 **多言語対応**（日本語、中国語簡体字、中国語繁体字、韓国語、英語）
  - 翻訳元の言語は自動検出されるため、指定するのは翻訳先だけ
- 🤖 **複数のLLMモデルに対応**
  - OpenAI: GPT-5.6 Sol / GPT-5.6 Terra / GPT-5.6 Luna
  - Anthropic: Claude Opus 5 / Claude Sonnet 5 / Claude Haiku 4.5
  - Google: Gemini 3.1 Pro / Gemini 3.8 Flash / Gemini 3.5 Flash Lite
  - メニューバーの「モデル」からいつでも切替可能（選択は自動保存）
  - APIキーの設定は「設定」→「API設定...」から
- 🎨 **翻訳スタイル選択**
  - ビジネス：フォーマルで丁寧な表現
  - 標準：スタイル指定なし
  - 友人：フレンドリーでカジュアルな表現
- ✏️ **自動校正機能**：元の言語を維持したまま文法・スペルを修正
- ⚡ **自動翻訳機能**：編集後2秒で自動翻訳（ON/OFF切替可能）
- 📡 **ストリーミング表示**：翻訳結果が生成されながら順次表示される
- 🛑 **中止機能**：実行中の翻訳・校正を「中止」ボタンで中断可能
- ⇄ **入れ替え機能**：翻訳元と翻訳結果を入れ替え、言語を自動推定
- 🕘 **翻訳履歴**：過去100件の翻訳・校正を保存し、いつでも呼び戻せる
- 💾 **自動保存**：テキストとウィンドウサイズを終了時に保存、起動時に復元
- 📝 **シンプルなUI**：PanedWindowによる左右2分割レイアウト
- 🖥️ **クロスプラットフォーム対応**：Windows、macOS、Linux

## 必要要件

- Python 3.8以上
- 以下のいずれかのAPIキー：
  - OpenAI API Key
  - Anthropic API Key
  - Google API Key

## セットアップ

起動スクリプトが仮想環境の作成・依存関係のインストール・アプリの起動をまとめて行います。
起動時に `git pull` が実行されるため、常に最新版で立ち上がります。

### Windows

1. リポジトリをクローンまたはダウンロード
2. `start_win.bat` をダブルクリック

### macOS / Linux

1. リポジトリをクローンまたはダウンロード
2. ターミナルで `chmod +x start_mac.sh` を実行
3. `./start_mac.sh` を実行

初回起動時は仮想環境の作成と依存関係のインストールに数分かかります。

## 使い方

### 初回起動

1. アプリケーションを起動
2. 「設定」メニューから「API設定...」を選択
3. 使用したいプロバイダーのAPIキーを入力（複数入力可）
4. 「保存」をクリック

APIキーを入力すれば、対応するモデルが自動的に選択されて翻訳が使えるようになります。
使用するモデルを変更したいときは、メニューバーの「モデル」から選び直してください。
現在使用中のモデルは右ペイン上部に表示されます。

### 翻訳

1. 「翻訳先」の言語を選択（翻訳元は自動検出）
2. 「スタイル」を選択（ビジネス／標準／友人）
3. 左側のテキストエリアに翻訳したいテキストを入力
4. **手動翻訳**: 「翻訳 →」ボタンをクリック
5. **自動翻訳**: ONにすると、編集の手が止まって2秒後に自動的に翻訳されます
6. 右側のテキストエリアに翻訳結果が表示されます

自動翻訳のON/OFFは、左ペインの「自動翻訳」チェックボックスと
「設定」メニューのどちらからでも切り替えられます。

### 校正

1. 左側のテキストエリアに校正したいテキストを入力
2. 「スタイル」を選択
3. 「校正」ボタンをクリック
4. 元の言語を維持したまま、文法・スペルが修正されます

### 翻訳履歴

メニューバーの「履歴」→「翻訳履歴...」（Ctrl+H）で開きます。

1. 上の一覧から見たい項目を選ぶと、下に原文と訳文が表示されます
2. 「復元」ボタン（または項目のダブルクリック）で、その翻訳を画面に呼び戻します
   - 原文が左のテキストエリア、訳文が右のテキストエリアに入り、
     翻訳先の言語とスタイルも当時の設定に戻ります
3. 不要な項目は「削除」、まとめて消すなら「すべて削除」

補足:

- 翻訳・校正のほか、自動翻訳の結果も記録されます
- 自動翻訳は入力が止まるたびに走りますが、**文字を打ち足しただけ**の場合は
  新しい項目を増やさず、直前の項目を更新します
  （文の途中に差し込んだ場合は別の翻訳として記録されます）
- 100件を超えると古いものから自動的に消えます
- 記録したくないときは「履歴」→「履歴を記録する」をOFFにしてください

### その他の機能

- **中止**: 翻訳・校正の実行中は「中止」ボタンで処理を止められます
- **入れ替え**: 「⇄ 入れ替え」で翻訳元と翻訳結果を入れ替え、言語も自動推定されます
- **コピー**: 「翻訳結果をコピー」ボタンでクリップボードにコピー
- **自動保存**: テキストとウィンドウサイズは終了時に保存され、次回起動時に復元されます
- **編集操作**: Ctrl+Z（元に戻す）、Ctrl+Y（やり直し）、Ctrl+A（すべて選択）などに対応。
  テキストエリアの右クリックからも同じ操作が行えます

## APIキーの取得方法

### OpenAI API Key
1. https://platform.openai.com/ にアクセス
2. アカウントを作成/ログイン
3. API Keys セクションで新しいキーを作成

### Anthropic API Key
1. https://console.anthropic.com/ にアクセス
2. アカウントを作成/ログイン
3. API Keys で新しいキーを作成

### Google API Key
1. https://aistudio.google.com/app/apikey にアクセス
2. Googleアカウントでログイン
3. 新しいAPIキーを作成

## トラブルシューティング

### Pythonが見つからない
- Pythonがインストールされているか確認してください
- PATHが正しく設定されているか確認してください

### 依存関係のインストールに失敗
- インターネット接続を確認してください
- `pip install -r requirements.txt` を手動で実行してみてください

### 翻訳が動作しない
- 「⚠ API設定を完了してください」と表示されている場合は、APIキーが未設定です
- APIキーが正しく設定されているか確認してください
- APIキーに十分なクレジットがあるか確認してください
- インターネット接続を確認してください

## セキュリティ

- APIキーは `config.json` に保存され、このファイルはGit管理から除外されています
- 翻訳履歴は `history.json` に保存されます。翻訳した文章そのものが含まれるため、
  このファイルもGit管理から除外されています（記録は「履歴」メニューからOFFにできます）
- 入力テキストに含まれる指示文を実行しないよう、プロンプトインジェクション対策を実装しています
